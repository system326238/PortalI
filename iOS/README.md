# Portal Invasion iOS SwiftUI Port

This folder contains a SwiftUI adaptation of the Java game for future iOS 18+ development in Xcode.

## Included files
- `PortalInvasionApp.swift`
- `Game/ContentCatalog.swift`
- `Game/PortalInvasionGameModel.swift`
- `Views/MenuView.swift`
- `Views/GameRootView.swift`
- `Views/ShopView.swift`
- `Views/WorldSelectView.swift`
- `Views/ProfileView.swift`
- `Views/GamePlayView.swift`

## Notes
- These files are generated on Windows and are intended for Xcode on macOS.
- This is a clean SwiftUI structure, not a compiled Xcode project.
- You will still need to open the folder in Xcode and create the app target if needed.
